## 🎯 How to Get Involved

**Miners**: Clone, build, start mining!
```bash
git clone https://github.com/Hicham60290/Auriumchain.git
cd Auriumchain && cargo build --release
./target/release/auriumchain --wallet YOUR_ADDRESS
```
