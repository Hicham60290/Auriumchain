## 💎 For Miners: Why Mine AuriumChain?

### Mining Specifications
- **Algorithm**: SHA-256 Proof of Work (same as Bitcoin)
- **ASIC Compatible**: Use your existing SHA-256 mining hardware
- **Block Reward**: 50 AUR (halving every 4,204,800 blocks)
- **Block Time**: ~30 seconds
- **Difficulty**: Dynamic adjustment for fair mining

### Mining Advantages
- ⚡ **Early Network**: Get in on the ground floor
- 💰 **Fair Launch**: No pre-mine, no ICO
- 🔧 **Easy Setup**: Simple CLI mining tools
- 🌍 **Decentralized**: P2P network with TLS 1.2+ encryption

### Start Mining Today!
```bash
git clone https://github.com/Hicham60290/Auriumchain.git
cd Auriumchain
cargo build --release
./target/release/auriumchain --wallet YOUR_WALLET_ADDRESS
```
